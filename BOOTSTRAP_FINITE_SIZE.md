# Snapshot bootstrap and finite-size confidence intervals

The workflow is deliberately split into two stages so every intermediate
distribution can be inspected and reused.

## 1. Bootstrap snapshots at each qubit size

Run `bootstrap_snapshot_observables.py` once for every JSON file generated by
`eval_gen_mea_data.py`.  Each bootstrap replicate samples `M` rows with
replacement inside every saved parameter group.  Therefore one replicate uses
exactly `h_length * M` snapshots.

TFI example:

```bash
python Diffushadow_run/bootstrap_snapshot_observables.py \
  --input data/tfi_N10_snapshots.json \
  --output data/bootstrap/tfi_N10_bootstrap.npz \
  --predict_model TFI \
  --M 10000 \
  --B 1000 \
  --d_values 1 2 3 4 5 \
  --seed 12345
```

Repeat this command for every finite size.  The script imports the same
median-of-means estimators used by `eval_new.py`; the default `--num_parts 10`
also matches `eval_new.py`.

Important model options:

- J1-J2: pass `--J1`; the saved scalar is interpreted as `alpha=J2/J1`, matching
  `eval_gen_mea_data.py`.
- XXZ: pass `--J_xy` when it is not 1.
- ANNNI h scan: use `--annni_scan h --annni_fixed_kappa ...`.
- ANNNI kappa scan: use
  `--annni_scan kappa --annni_fixed_h ...`.

The NPZ keeps the full distributions under `bootstrap_*`.  It also writes the
mean/std keys expected by the existing `inf_research` plotting scripts.  For
example, a TFI output can still be passed to:

```bash
python inf_research/plot_zz_inverse_qubit.py \
  --files data/bootstrap/tfi_N6_bootstrap.npz \
          data/bootstrap/tfi_N8_bootstrap.npz \
          data/bootstrap/tfi_N10_bootstrap.npz
```

That existing plotting script fits the finite-size means.  It does not by
itself propagate the bootstrap distributions into the infinite-size confidence
interval; use stage 2 for that.

## 2. Fit every bootstrap replicate versus 1/N

TFI ZZ example:

```bash
python inf_research/bootstrap_finite_size_ci.py \
  --files data/bootstrap/tfi_N6_bootstrap.npz \
          data/bootstrap/tfi_N8_bootstrap.npz \
          data/bootstrap/tfi_N10_bootstrap.npz \
  --observable_keys bootstrap_zz \
  --fit_degree 1 \
  --confidence 0.95 \
  --output_dir data/bootstrap/tfi_infinite \
  --plot \
  --param_label g
```

J1-J2 spin-dot and ANNNI structure-factor examples use, respectively:

```text
--observable_keys bootstrap_corr_spin_dot
--observable_keys bootstrap_structure_factor_pi bootstrap_structure_factor_pi_over_2
```

If `--observable_keys` is omitted, every common `[B,H]` or `[B,D,H]`
`bootstrap_*` array is fitted.  Use `--components`/`--distances` only when all
selected observables are component-resolved arrays.

For bootstrap replicate `b` and parameter `g`, stage 2 performs the same fit as
the existing `inf_research` scripts:

```text
observable_N(b, g) = polynomial(1/N)
observable_infinite(b, g) = polynomial intercept at 1/N = 0
```

The output CSV reports the fit of the finite-size means, bootstrap
mean/median/std, and percentile confidence limits.  The output NPZ additionally
stores every fitted infinite-size intercept, so alternative intervals or plots
can be produced without repeating stage 1.

At least `fit_degree + 1` distinct qubit sizes are required.  More sizes are
strongly preferable because a two-size linear fit has no redundancy for
checking finite-size model adequacy.
